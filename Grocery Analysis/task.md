# Анализ падения оборота сервиса доставки продуктов

## Контекст

Вы работаете аналитиком в сервисе доставки продуктов из магазинов.

**Пользовательский путь:**
```
Приложение/Сайт → Поиск товаров → Карточка товара → Корзина → Оформление заказа → Оплата
```

**Проблема:**  
Команда продукта заметила, что в последнем месяце начал снижаться оборот сервиса. Руководство просит провести исследование и понять, что стало причиной ухудшения ключевой бизнес-метрики.

**Доступные данные:** 6 месяцев истории по трём направлениям:
- Заказы
- Пользовательская воронка
- Маркетинговые коммуникации

---

## Цель задания

> **Понять причину падения оборота (GMV) сервиса за последний месяц**

| `store_id` | object | ID магазина-исполнителя |
| `city` | object | Город клиента |
| `platform` | object | Платформа: `ios` / `android` / `web` |
| `order_created_at` | datetime | Дата и время оформления |
| `order_date` | date | Дата заказа (для группировки) |
| `delivery_slot_start` | datetime | Начало интервала доставки |
| `items_count` | int | Количество товаров в заказе |
| `gross_merchandise_value` | float | Стоимость до скидок (GMV) |
| `discount_type` | object | Тип применённой скидки |
| `discount_amount` | float | Размер скидки |
| `delivery_fee` | int | Стоимость доставки |
| `service_fee` | float | Сервисный сбор |
| `paid_amount` | float | Итоговая оплата клиента |
| `payment_method` | object | Способ оплаты |
| `campaign_id` | object | ID маркетинговой кампании |
| `experiment_group` | object | Группа: `test` / `control` / `no_campaign` |

### 2️. Пользовательская воронка (`funnel_df`)

> Каждая строка — одна пользовательская сессия

**Этапы воронки:**
```
Заход в сервис
   ↓
Поиск товара
   ↓
Просмотр карточки
   ↓
Добавление в корзину
   ↓
Переход в корзину
   ↓
Покупка
```

| Поле | Тип | Описание |
|------|-----|----------|
| `session_id` | object | Уникальный идентификатор сессии |
| `client_id` | object | ID клиента |
| `address_id` | object | ID адреса |
| `session_start_at` | datetime | Время начала сессии |
| `session_date` | date | Дата сессии |
| `city` | object | Город |
| `platform` | object | Платформа |
| `traffic_source` | object | Источник трафика |
| `campaign_id` | object | ID кампании |
| `experiment_group` | object | Группа эксперимента |
| `timing_period` | object | Период отправки коммуникации |
| `service_visit` | int | Флаг захода в сервис |
| `product_search` | int | Флаг поиска товара |
| `product_card_view` | int | Флаг просмотра карточки |
| `add_to_cart` | int | Флаг добавления в корзину |
| `cart_visit` | int | Флаг перехода в корзину |
| `purchase` | int | Флаг покупки |
| `order_id` | object | ID заказа (если покупка) |
| `search_at` | datetime | Время поиска |
| `product_card_view_at` | datetime | Время просмотра карточки |
| `add_to_cart_at` | datetime | Время добавления в корзину |
| `cart_visit_at` | datetime | Время перехода в корзину |
| `purchase_at` | datetime | Время покупки |

### 3️. Маркетинговые коммуникации (`marketing_df`)

| Поле | Тип | Описание |

## Связи между таблицами


| Ключ | Назначение |
|------|-----------|
| `client_id` | Связь пользователя между **всеми** таблицами |

| `order_id` | Связь покупки в воронке ↔ заказ |

| `experiment_group` | Анализ A/B-тестов и контрольных групп |
